Other revision pages are retained in this folder for targeted lookup and are
excluded from normal site search/navigation. Old source paths and hash manifests
may describe the pre-cleanup tree; use Git history for that snapshot. Native
hardware sources remain under `hardware/`, not in this documentation archive.

Do not copy this history back into current pages or append a running revision
log. Update the current design in place; Git records those changes. Some notes
were still uncommitted during cleanup, so they are preserved here rather than
assuming they already exist in Git history.
