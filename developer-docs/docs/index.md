# Buttplug Compass

Start with the [manufacturing design proposal](prototype-build-handoff.md).
It replaces the earlier scaffold with four main mechanical pieces: CNC-turned body,
CNC-turned motor/thermistor cap, open flange tray and rear cover. A separate silicone boot
and standard insulation/foam remain part of the assembly.

The previous P1 dry-fit kit is withdrawn as the recommended build. The new CAD
is a manufacturing study, not a build/tooling release. Battery choice is open.
No physical build, powered operation or wear validation exists.
