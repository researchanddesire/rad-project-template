# PCB Overview

Document the product PCB source boundary and production package here.

| Asset | Location | Notes |
| --- | --- | --- |
| PCB source folder | [`hardware/pcb/`](../hardware/pcb/) | PCB design files, fabrication notes, and production exports. |

If `hardware/pcb/` contains a KiCad board file (`*.kicad_pcb`), the Ohai
assembly-docs build can copy it into the published site and embed a KiCanvas
viewer.
