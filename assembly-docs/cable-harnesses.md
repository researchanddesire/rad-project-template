# Cable Harnesses

Document cable harness sources and generated Wireviz artifacts here.

| Asset | Location | Notes |
| --- | --- | --- |
| Cable source folder | [`hardware/cables/`](../hardware/cables/) | Wireviz YAML sources belong here. |

Product BOMs list cable harnesses as top-level assemblies. Detailed cable BOMs
belong to Wireviz output, such as generated `.bom.tsv` artifacts, not duplicate
rows in `hardware/bom.csv`.
