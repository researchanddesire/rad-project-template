# Assembly Guide

Document the build in the order a careful builder should perform it.

## Before You Start

- Review the [Bill of Materials](bom.md).
- Gather the required tools and shop supplies.
- Inspect printed, machined, PCB, cable, and off-the-shelf parts.

## Step 1

Add photos under `assembly-docs/assets/` and reference them with relative links:

```markdown
![Installed example](assets/example-installed.jpg)
```

## Final Checks

- Confirm all fasteners are seated.
- Confirm wiring is routed safely.
- Confirm firmware or calibration prerequisites are complete.
